⚙ WebServ

C++98 HTTP/1.1 epoll 42 School Project

A lightweight, high-performance HTTP/1.1 web server written in C++98. Supports CGI, file uploads, session management, directory listing, and custom routing — all driven by an epoll event loop.

🔌

CGI Scripts

Execute dynamic Python, PHP, and Shell scripts via the CGI/1.1 interface. Try the built-in test script to see live output.

Session Management

Cookie-based login, registration, and logout flow handled entirely by CGI scripts on the server.

✅ Server Capabilities

✓ HTTP/1.1 protocol (RFC 2616)
✓ GET, POST, DELETE methods
✓ Non-blocking I/O with epoll
✓ Multiple virtual servers
✓ Custom error pages (4xx / 5xx)
✓ CGI support (.py, .php, .sh)
✓ Chunked transfer encoding
✓ HTTP redirections (301/302)
✓ Configurable max body size
✓ Per-route method restrictions
✓ Client timeout management
✓ C++98 standard compliant

🚀 Quick Start

git clone https://github.com/yssrexe/webservHTTP.git
cd webservHTTP
make
./webserv                        # uses webserv.conf by default
# open http://localhost:8081/
